## 承载方式：直接挂载（v6.51 起，彻底放弃 iframe）

v6.48（iframe srcDoc）、v6.49（iframe 独立文档地址）、v6.50
（iframe + 加载诊断）三版在用户真机上都没能把平台跑起来。v6.51
起改为直接挂载：构建时抽取脚本把平台的样式与脚本抽成普通 CSS /
JS 文件随工作台一起打包，运行时平台直接挂进工作台的 React 树、
跑在工作台自己的文档里——没有 iframe、没有独立文档地址、没有
postMessage。平台的内联 on* 处理器一律由工作台的事件委托接管
（见 `delegate.ts`）：不光是因为浏览器安全策略可能拦下内联处理
器，更因为平台函数都关在 `bootLaoluo` 的作用域里、没挂到全局，
原生处理器按名字根本调不到它们（沙箱实测会报「xxx is not
defined」）；委托挂在捕获阶段、派发完即拦下事件，原生处理器不
会被二次触发。平台样式全部限定在 `.laoluo-host` 容器内，不影
响工作台任何页面。

## 文件分工（平台本体保持单一独立单元）

- `source.html` —— 平台原件的接入副本，**替换新版时只换这一个文件**。
- `sync.mjs` —— 构建时抽取脚本（手动运行，不挂构建命令）：读
  `source.html`，抽出样式与脚本，生成 `generated.css` /
  `generated.js` / `generated.d.ts`。抽取带全套断言与审计：CSS 逐
  条规则加 `.laoluo-host` 前缀（html, body 规则丢弃、@keyframes
  步骤不加前缀）；JS 包成 `bootLaoluo(mountEl)`（不挂 window），
  做锚点替换（app 指向挂载点、文件输入框改容器内查询、toast 改挂
  容器内、`DEFAULT_TOKEN` 强制置空、window 监听器与定时器改走追
  踪包装器以便关窗时摘监听保活），用 TypeScript 编译器 API 确定
  性收集全部顶层函数进 handlers 字典，并审计全部 on* 模板的文法
  （全动态模板 `onclick="' + fn + '"` 静态验不了，脚本会单列出
  来，靠运行时委托的大声报错兜底）。任何锚点找不到 / 次数不符 /
  模板出现文法外形式，脚本立即报错停下，绝不静默跳过。
- `generated.css` / `generated.js` / `generated.d.ts` —— 抽取产物
  （不要手工编辑），随工作台打包发出。`generated.js` 导出
  `LAOLUO_SOURCE_HASH`（source.html 的 SHA-256 前 16 位），覆盖窗
  左下角诊断区会显示它：**换了 source.html 却没重跑抽取时，指纹
  对不上，一眼能看出来。**
- `delegate.ts` —— 工作台侧运行时支撑（不是平台本体）：原生内
  联处理器探针与 style 属性探针（结果只作诊断显示）、祖先遍历
  事件委托分发器（9 种事件、捕获阶段派发并屏蔽原生触发）、
  style 水合观察器。解析器与 sync.mjs 的审计同口径，出错大声
  上报、逐节点容错。
- `../videogen.tsx` —— wrapper（与平台本体分离）：顶栏按钮总线 +
  全页覆盖窗口（关窗只隐藏保活）+ 直接挂载（只启动一次、双探针、
  启动失败错误层 + 重试）+ 生命周期（关窗 suspend 摘平台 window
  快捷键并暂停音频、生成轮询保留；开窗 resume 重算画布）+ 诊断
  区与处理器错误横幅。平台代码不进 wrapper，wrapper 不碰平台内
  部状态。

## 密钥口径（硬性）

- `source.html` 接入时 `DEFAULT_TOKEN` 已为空，且 `sync.mjs` 每次
  抽取都强制置空——换新版文件后只要跑一遍抽取，打包产物里就不
  会带任何内置 Token。Token 的值不得写进任何代码、注释、日志或
  文档。
- autodl Token 与 DeepSeek Key 由用户在平台右上角「密钥」对话框
  里各填各的，只存本机浏览器 localStorage（键名 `llpub-*`，与原
  件一致），不进工作台数据库、不进备份包。素材存浏览器
  IndexedDB（`ll-platform-pub`），同样只在本机。
- 不填 Token 时平台是演示模式：只走流程、不出真视频、不花钱。

## 替换新版平台的流程（用户在 GPT 升级后发来新版文件时）

0. **先确认新版文件是以当前 `source.html`（v6.59 新底版，SHA-256
   770bff5e…）为底改出来的**：让 GPT 拿本版文件去改；若发来的文件
   是拿旧版改的，先把 v6.52 的画布重构（卡片降噪/编辑条/LOD/色点/
   HUD 分层）、v6.53 的一键整理画布（整理/撤销整理）、v6.54 的
   双岛顶栏/dock/锚点卡/左进右出连线/小地图、v6.55 的四问题修复、
   v6.56 的连线重做、v6.57 的小地图雷达/项目菜单重做与 v6.58 的
   分镜 H3 批量生成、v6.59 的批量体验重做（面板三区/真实进度/
   再次抽卡版本管理/密钥持久化修复）移植过去再往下走，不得直接覆盖。
1. 用新版文件覆盖本目录的 `source.html`（只换这一个文件，不动
   工作台其他任何代码）。
2. 在仓库根目录执行 `bun client/src/laoluo/sync.mjs` 重新抽取
   （必须过全部断言与模板审计；脚本报错停下时，先人工看一眼新
   版的结构变化再改脚本，不要绕过断言）。
3. 重新构建工作台并验证：打开「生成视频」覆盖窗，确认画布渲染、
   建卡/连线/绑定、密钥对话框打开与保存、演示模式能跑完、关窗
   回工作台且状态不受影响；核对诊断区里的产物指纹与新文件对得
   上；再回读一遍工作台正式数据（达人/卡片/项目/记录等）确认与
   换版前一致。
4. 验证通过后上线。真实生成（填自己的 Token/Key 后出视频）只由
   用户本人在真机亲手跑，沙箱与构建流程永不代跑。
